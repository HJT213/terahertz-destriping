# terahertz-destriping

面向玻纤复合材料太赫兹图像的条纹去噪与候选缺陷分析工具。网页支持导入图像、切换两种频域滤波器、分区调整对比度，并查看和导出去噪结果、分割图及面积统计。图像由浏览器在本机处理，文件不会上传到服务器。

[打开在线演示](https://hjt213.github.io/terahertz-destriping/)

## 项目简介

太赫兹图像中的周期性条纹会干扰灰度观察和后续分割。本项目将原 MATLAB 工程 `app1.mlapp` 的处理流程迁移到网页，便于查看同一张图像在不同滤波与分割参数下的变化。工作台并排显示原始灰度图、去噪图、灰度增强图和二值分割图，处理前后保留相同的图像尺寸。

## 在线演示

1. 打开网页，点击 **试用演示图**，或通过 **导入图像** 选择自己的文件。演示图由浏览器生成，包含横纵条纹和三个模拟低灰度区域。
2. 保持默认参数，点击 **运行分析**。先对照原始图和去噪图观察条纹变化，再查看分割图中的白色区域和下方统计。
3. 在左侧切换滤波器，或调整灰度区间、形态学参数和最小连通面积，再点击 **运行分析** 查看结果。
4. 点击各图下方的 **PNG** 按钮保存对应图像。点击 **导出分析记录** 下载 JSON，其中包含输入图像信息、滤波与分割参数、统计结果和处理提示。彩色输入的「原始图像」按灰度图显示并导出。

## 技术方案

- **条纹去噪**　使用二维快速傅里叶变换（FFT）在频域处理条纹。十字扇形滤波器利用频谱投影定位次峰，分别按横、纵方向的角度与偏移量构造滤波掩膜。非标准条纹伪影滤波器使用 `f1`、`f2` 和 `θ` 调节频域滤波权重。
- **区域灰度增强**　将去噪图分为左上、右上、左下和右下四块，对各区分别进行灰度拉伸。默认区间为 `[0, 1]`，保留该区域的灰度。
- **候选缺陷分割**　增强图依次经过中值滤波、灰度反转和 Otsu 自动阈值分割，再通过开运算、移除小连通区域和闭运算整理掩膜。可选择圆盘或正方形结构元素，也可选择按 4 邻域或 8 邻域移除小区域。
- **统计与标定**　按 8 邻域统计最终二值图中的白色连通区域，显示候选缺陷数量、总面积、面积占比和处理耗时。已知横纵像素间距相同且为 `s mm/px` 时，可填写 `s`，系统按「白色像素数 × s²」换算为 mm²。留空时按像素数统计。
- **浏览器实现**　使用 HTML、CSS 和原生 JavaScript。Canvas 负责图像读取与显示，Web Worker 在浏览器后台线程中执行计算。部署只需静态托管，无需安装 MATLAB 或搭建计算后端。

## 合成演示结果

对内置的 384 × 384 演示图保留默认处理参数，仅切换滤波器。面积占比为分割图中白色像素数占整幅图像像素数的百分比。

| 滤波器 | 候选区域数 | 总面积（像素数） | 面积占比 |
| --- | ---: | ---: | ---: |
| 十字扇形滤波器 | 3 | 7,478 | 5.07% |
| 非标准条纹伪影滤波器 | 3 | 7,466 | 5.06% |

以上结果可用于复现演示流程。处理真实样品时，请结合原图核验候选区域，材料纹理和背景变化也可能被分割出来。网页版尚未完成与 MATLAB 原版的逐像素一致性验证。

## 支持的输入

支持 PNG、JPEG、BMP 和 WebP。文件最大 20 MiB，图像每边需为 8–2,048 像素，总像素数不超过 2,097,152。内部按 8 位灰度处理。TIFF、MAT、高位深科学图像和原始太赫兹波形需先转换为受支持的 8 位图像，才能在网页中使用。
